# Documentation

Start with the [project README](../README.md), then choose a guide:

| Guide | Contents |
|---|---|
| [Setup and usage](SETUP.md) | Environment, source ingestion, execution configuration, live commands and troubleshooting |
| [Architecture](ARCHITECTURE.md) | Roles, modules, evidence flow, routing and delivery contracts |
| [Retrieval](RETRIEVAL.md) | Filesystem/Chroma responsibilities, chunking, index setup and resource limits |
| [Evaluation and limitations](EVALUATION.md) | Demonstrated report outcomes, quality interpretation and remaining work |
| [Development](DEVELOPMENT.md) | Repository layout, focused validation, preservation and contribution rules |
| [Diagram assets](diagrams/README.md) | Conceptual PNGs and editable topology references |

These are maintained public guides. Historical redesign plans, campaign logs,
closed ledgers, source documents and reports remain local and are excluded from
the current Git tree. They are not prerequisites for a fresh checkout. Existing
Git history is retained; this cleanup does not rewrite earlier commits.

A Markdown index is sufficient for the current CLI product. The proposed
Workflow Studio would visualize planning, research, RAG, evidence selection and
review from canonical run artifacts, but its upgraded UI has not been delivered.
