## Historical specifications

The [redesign package](redesign-package/00-START-HERE.md) records the original
architecture and staged implementation instructions. Later authorized changes
supersede its early model and budget policy. The [archive](archive/README.md) is
historical reference, not a second active implementation.

Diagram PNGs use a custom illustrated layout; companion Graphviz files preserve
editable topology references. See [diagram assets](diagrams/README.md). No
documentation server, model call or dependency download is needed to read this index.
